# E-Commerce Sales Analysis using Python

## 📊 Project Overview
A portfolio-ready Python data analytics project analyzing **10,000 e-commerce transactions** using Pandas, NumPy and Matplotlib.

The project demonstrates an end-to-end workflow: data loading, quality checks, feature engineering, KPI calculation, exploratory analysis, visualization and business recommendations.

## 🎯 Business Questions
- What are total sales, profit, orders and average order value?
- Which categories and products generate the most revenue?
- Which regions perform best?
- What are the monthly sales trends?
- Which payment methods are most popular?
- How does discounting relate to profit?
- Which customers contribute the most revenue?

## 🛠️ Tools
- Python
- Pandas
- NumPy
- Matplotlib
